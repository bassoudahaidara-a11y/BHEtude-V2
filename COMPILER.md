# BH Étude v2 : compiler l'APK
1. Dépôt GitHub : envoie tout le contenu de ce dossier (.github compris).
2. Actions > Build APK > Run workflow, puis télécharge « BH-Etude-APK » (app-debug.apk).
3. Dans l'app, touche « Clé » : colle ta clé Groq (console.groq.com/keys) et, pour la messagerie,
   l'adresse de ta base Firebase (Realtime Database en mode test). Ton ami utilise la MÊME adresse.
